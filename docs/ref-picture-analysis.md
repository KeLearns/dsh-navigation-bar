## 一、统一视觉结论（四图交叉验证）

### 1. 位置与结构
- 导航条是**竖直方向的窄条**，位于**左侧边栏右缘与主消息区之间、分界线的右侧**；条背景透明/与页面同色，右侧有 1px 垂直分界线。
- 非悬停态条宽约 **25-32px**，高度占满聊天可视区（顶部标题栏下方、底部输入框上方），上下各留约 10-15px padding。
- 每个键 = 一根**水平短线**，锚定一个用户对话轮次；从上到下按时间正序排列；键数 = 消息轮数（参考图约 16-25 根）。

### 2. 键的几何（建议实现取值，参考图估算有 ±）
| 属性 | 估算区间 | 建议默认 |
|---|---|---|
| 键高（线粗） | 2-4px | 3px |
| 默认(最短)长度 | 8-22px（浅色图偏大 20-22px，深色图偏小 8-12px） | 14px |
| 悬停(最长)长度 | 22-100px（≈最短的 2.5-5 倍） | 56px（4 倍） |
| 键间距（中心距/槽位） | 16-22px | 20px |
| 圆角 | 右端 2-3px 胶囊，左端平切 | border-radius 2px |
| 键材质 | 纯色，非渐变 | — |

### 3. 悬停动效（核心）
- 被悬停键：**变长 + 变色**（浅色加深至 #374151/#1F2937 或 #666-888；深色变亮至 rgba(210,210,235,.9+)），向左固定、向右伸长。
- 上下相邻键**对称阶梯递减 3 级，第 4 邻恢复最短**：
  - 悬停键（level 0）：100%
  - ±1 邻（level 1）：约 60-70%
  - ±2 邻（level 2）：约 45-50%
  - ±3 邻（level 3）：约 30-35%
  - ±4 邻及更远：恢复默认最短
  - 颜色/亮度随阶梯同步逐级过渡，形成"山峰"形。
- **边界键**：悬停首/尾键时，不存在的一侧自然裁剪，阶梯只向有键的一侧展开，不溢出。
- 动画：width + background-color transition 200-300ms ease-out，同步展开/收起。

### 4. 非悬停态
- 所有键**保持最短长度**；对应当前页面正在查看内容的那个键**高亮**（长度基本不变，仅颜色更亮/更深）。
- 浅色图显示激活键左端有一个 4-6px 小圆点标记（可选实现为 active 态的 ::before 圆点或单纯提亮）。
- 高亮位置随主区滚动/内容切换实时更新；非悬停不显示气泡。

### 5. 气泡弹窗（tooltip）
- 出现在被悬停键的**右侧**，垂直方向与键中心对齐（略偏上），与键间距 4-12px，覆盖在主消息区之上。
- 宽度约 200-320px；圆角 8-12px；1px 边框 + 轻阴影（0 2px 8px rgba(0,0,0,.08-.15)）；内边距 10-14px。
- 内容结构（严格按需求）：
  - **用户消息**：第一行，加粗（500-600），13-14px，单行「text-overflow: ellipsis; white-space: nowrap; overflow: hidden」。
  - **模型消息**：后续，常规字重，12-13px，行高 1.4-1.5，**最多 3 行**，「display:-webkit-box; -webkit-line-clamp:3; -webkit-box-orient:vertical; overflow:hidden」。
- 出现/消失：opacity + translateX 淡入 150-200ms，约 80-200ms 防闪烁延迟。

## 三、实现规格要点（汇总 agent）

1. **DOM/定位**：piano-bar 作为与 sidebar 平级的「position: absolute」叠加层（固定在分界线右侧）；键用「button」+ 内部「span」（hit area 约 30px 高，大于视觉 3px，便于触达）；tooltip 用**单例 DOM + Portal 挂载**（避免 overflow 裁剪）。
2. **阶梯驱动**：hover 时按「distance = |index - hoverIndex|」给键写「data-offset="0..3"」（≥4 恢复默认），CSS 按属性取长度比例（1 / .65 / .47 / .3）。
3. **主题**：一套「--piano-*」CSS 变量，跟随 DSH 主题（监听 documentElement class/style 变化 + prefers-color-scheme 兜底）。
4. **截断**：用户行单行 ellipsis；模型行 -webkit-line-clamp: 3。
5. **联动**：IntersectionObserver / 滚动容器监听 → 计算当前视口内容对应的用户消息 → 设置 active 键；点击键滚动到对应消息。
6. **风险清单**：z-index 层级（条 < tooltip < 全局弹层）；overflow 冲突用 Portal；键数过多时槽位压缩/滚动；主题切换脏色；200+ 消息性能；边界键裁剪；防抖。
